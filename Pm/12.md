**JS - JavaScript** je způsob jak používat "seriózní" programovací jazyk na webových stránkách z klientské strany.
JS je just in time kompilován (narozdíl od PHP), jeho hlavní využití jsou:
- dynamická změna CSS 
- Ověřování vstupu
- Komunikace s PHP bez využití \<form> nebo inline php
- tvorba reaktivní webové stánky

## Vložení scriptu

*zde je menší poznámka... JS může pracovat s JS knihovnami které potřebují specifický způsob vložení, ty ale nebudu ukazovat

### 1. element \<scrip> (bez src)
v podstatě ekvivalent elementu \<style> pro CSS ale standardně se dává na konec elementu \<body> hlavně pro čitelnost
```html
<body>
<span id="out"></span>
<script>
    let aCoolText = "trust me this text is very cool";
    document.getElementById("out").innerText = aCoolText;
</script>
</body>
```

### 2. element \<script> (se src)
opět velice podobný CSS, jen místo rozdílného elementu (link) přidáme src atribut pro element \<script>
```js
// script.js

let aCoolText = "trust me this text is very cool";
document.getElementById("out").innerText = aCoolText;
```
```html
<body>
    <span id="out"></span>
    <script src="script.js"></script>
</body>
```

### 3. JS atributy
html má několik atributů spojených s JS, např artribut onclick spustí JS při kliknutí
```html
<body>
    <button onclick="add()">CLICK ME</button>
    <span id="out"></span>
        <script>
        let clickAm = 0;
        function add() {
            clickAm++;
            document.getElementById("out").innerText = `you clicked the button ${clickAm} times`;
        }
    </script>
</body>
```
