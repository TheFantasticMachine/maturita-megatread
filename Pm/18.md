## Nejčastější příkazy

### 1. SELECT

Příkaz `SELECT` souží k výběru dat z databáze. Kompletní `SELECT` dotaz bude obsahovat další příkaz - `FROM` - ten
slouží pro výběr zdrojové tabulky ve vybrané databázi.
Příklad dotazu `SELECT` bude vypadat takto:
```sql
SELECT [parametr] FROM jmeno_databaze;
```
Příkaz `SELECT` vyžaduje svůj parametr, ten může být:
- název jednoho sloupce
- název více sloupců
- parametr * vybere všechny sloupce

**Příklady** (na tabulce `Authors`):
```sql
-- 1 jeden sloupec
SELECT Name From Authors;

-- 2 více soupců
SELECT  Name, Country, BirthYear FROM Authors;

-- 3 výběr pomocí *
SELECT * FROM Authors;
```

### 2. WHERE

Příkaz `WHERE` je veeeeeelice complexní. Pro jeho pochopení ho můžmeme nazvat jako filtr,
nebo tomu můžeme říkat příkaz podobný příkazu if. Abych byl specifický, `WHERE` dodává podmínku pro select.
Ale protože extuje obrovské množství datových typů, což znamená že je ještě větší množství jak je filtrovat.
... A ještě před tím než začnu popisovat jednotlivé způsoby, je dobré si pamatovat že syntax SQL má ; na konci řádku, takže
```sql
SELECT *
FROM Authors;
```
... je stále validní dotaz.

**Relační operátory** ([viz otázka 1](1.md)) v jazyku SQL jsou:
- **=** ... typické rovná se lze použít na čísla text a celkově cokoliv
- **\>** ... více než se používá pouze pro čísla
- **<** ... méně než se používá pouze pro čísla
- **\>=** ... více než nebo rovná se, je také pouze pro čísla
- **<=** ... méně než nebo rovná se, je pouze pro čísla 
- **\<>** ... nerovná se ...**není** pouze pro čísla, občas se používá **!=** 
- **`BETWEEN`** ... je způsob jak vybrat věci v rozmezí a to jak číslně tak alfabeticky, jeho syntaz je spojený s dalším 
příkazem `AND` a vypadá takto:
```sql
-- výběr čísleně
SELECT * FROM Authors
    WHERE BirthYear BETWEEN 1900 AND 2000;
-- výběr alfabeticky
SSELECT * FROM Authors
    WHERE Name BETWEEN 'Agata Christie' AND 'George Orwell';
```

**Další Wildcards:**
- **%** ... označuje jakýkoliv znak v neomezeném množství (tedy př: %red% vybere třeba: "she's a **red**head", "a **red** pencil", ale pokud by wildcard byl pouze red% nebyly by vybrány protože red musí být na začátku př. "**red**head" (hey odebral jsem část abych vyhověl querry, dobrá věc na hádání - redundance, očekávané querry a jak upravit databázi))
- **_** ... označuje místo pro znak (př v druhém dotazu, vybral jsem pouze žánry které mají **přesně** 7 znaků)

*...existují ještě wildcards {}, [], ^, - ale podle w3 schools nefungují v mySQL což jsme používaly ve škole celpu dobu (více [zde](https://www.w3schools.com/sql/sql_wildcards.asp))*

- **`IN`** ...podobný `BETWEEN` ale místo rozmezí definujeme jediné možnozti (seznam validních možností)
```sql
SELECT * FROM Books
WHERE Genre IN ('Dystopian', 'Mystery');
```

Relační operátor lze doplnit Logickými 
- **NOT** ... negace hledání
- **AND** ... spojení podmínek
- **OR**  ... různé podmínky

```sql
SELECT * FROM Authors
    WHERE [podmínka] AND/OR [podmínka];

SELECT * FROM Authors
    WHERE NOT [podmínka];
```

Výsledek lze seřadit příkazem `ORDER BY`, ten se píše za `WHERE` (ano v SQL záleží na pořadí).
### 3. CREATE

```sql
CREATE DATABASE Maturita;
USE maturita;
    
CREATE TABLE Authors(
    AuthorID  int auto_increment primary key,
    Name      varchar(255) not null,
    Country   varchar(255) not null,
    BirthYear int          not null
);
CREATE TABLE Books (
    BookID   int                                                                   not null primary key,
    Title    varchar(255)                                                          not null,
    Genre    enum ('Dystopian', 'Fantasy', 'Horror', 'Mystery', 'Fiction', 'none'),
    Price    decimal(5, 2)                                                         not null,
    AuthorID int                                                                   null
);
```
