# 11. CSS - charakteristika, syntaxe, jednotky, identifikátory

---
**CSS - Cascading Style Sheets** je jazyk sloužící ke změně vzhledu webové stránky. Tedy mění a upravuje vzhled jednotlivých elementů.

<!DOCTYPE html>
<html lang="cz">
<head>
<title> 11 - CSS</title>
<style>
.plus {
    color: greenyellow;
    font-weight: 700;
    display: block;
}
.plus:before {
    content: "+ ";
}
.con {
    color: red;
    font-weight: 700;
    display: block;
}
.con:before {
    content: "- ";
}
</style>
</head>
</html>

## "aktivace" CSS

### 1. Inline

Pokud chceme aplikovat css pouze na jeden element lze využít jeho atribuytu style="" který dovoluje zapsat css pro element s tímto atributem
<span class="plus"> pokud používáme JS pro změnu css elementu stějně k jeho tvorbě dojde, není nic špatného na takovém zápisu </span>
<span class="con"> lze elegantně nahradit pomocí atributu id kteý slouží jako uinikátní identifikátor elementu, případně doplnit css pseudo classy :nth-child() </span>

### 2. zápis do elementu \<style>

V moment kdy chceme zapsat css které se bude aplikovat pouze na specifický dokument můžeme ho zapsat do elementu \<style>
<span class="plus"> dovoluje nám využívat jen jeden dokument na celou stánku</span>
<span class="plus"> ideální pro sobory ke stažení pro jakéhokoliv uživatele protože nevtyžadují žádný setup </span>
```html
<head>
    <style>
        body {
            margin: 0;
            box-sizing: border-box;
        }
    </style>
</head>
```

### 3. Tvorba CSS dokumentu

Pokud vyvoříme CSS dokument můžeme ho spojit s html dokumentem pomocí značky link
<span class="plus"> ideální pro tvorbu dlouhých a velkých dokumentů které aplikujeme na neomezené množství souborů </span>
<span class="con"> při tvorbě stránky může trvat než je zaznamenaná změna css dokumentu </span>
<span class = "con"> je třeba zadávat správnou cestu k dokumentu

```html
<head>
    <link rel="stylesheet" href="cesta/k/css/souboru">
</head>
```
