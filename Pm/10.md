# 10. HTML - charakteristika, struktura dokumentu, syntaxe, validita, druhy a kategorie značek

---

**HTML - HyperText Markup Language** je standardní programovací jazyk pro tvorbu webových stránek,
často je ve skupině jazyků jako JavaSrcipt, CSS nebo PHP. Pro tvorbu obsahu využíváme značky které vytvářejí
elementy.

---
## Tvorba elementů

Elementy se vytváří zadáváním jednotlivými "značkami" (anglicky tag). Tyto značky mohou být jednotné nebo párové.

- **Párové:** musejí být otevřeny a uzavženy (př. \<p> text text text \</p>)
- **Samostanté:** fungují samy o sobě a nemusejí být uzavřeny (př. elementy jako \<img> \<link> \<hr> \<br> ...)

Samostatné značky mohou automaticky dávat vlastnosti (např. \<h1> vytvoří velký tučný text který bude zabírat celý řádek)
ale tyto vlastnoti mohou být změněny pomocí jazyku CSS

Dále jsme schopni přiřadit elementu atributy, některé elementy je vyžadují pro správné fungování. Atribut rozšiřuje schopnosti a vlastnosti elementu
(např. atributy jako: href, class, style, id, type ...)

---
## Základní elementy

1. ### základní set
- **\<head>** - označuje část dokumentu která není zobrazena, jejím úkolem je "nastavit" dokument, např definujeme zde jazyk stránky, odkzaujeme k dalším soborům nebo stránkám atd...
- **\<body>** - označuje část dokumentu která je zobrazena, vetšina elementů bude patřit sem
- **\<html>** - označuje část která je psána v html (v moment kdy píšeme do jednoho dokumentu např. PHP, JS, CSS a HTML každý by měl být správně označen ale nevyžaduje velkou interakci)
- **\<!DOCTYPE html>** - označuje html dokument
- **\<link>** - slouží ke spojení souborů pomocí odkazu... efektivně to je html verze příkazů jako import nebo include
- **\<meta>** - meta element který slouží k definování metadat stránky (př. jazyk stránky) 
- **\<title>** - jméno stánky<br>
***...toto jsou základní elementy které by měl/musí mít každý html dokument před tím než začneme vytvářet viditelný obsah*** 
2. ### text
- **Nadpis**
   - má 6 velikostí
   - automaticky mají vlastnosti jako Bold a display block (bude zabírat
   celý řádek sám o sobě)

  - značnaka elementu je **\<h1>** (nebo jakékoliv číslo 1 až 6 ) a musí být uzavřen

- **Paragraf**
  - je tvořen párovou značkou **\<p>**
  - text uvnitř bude mít ze základu vlastnost display block
- **Prostý text**
  - v podstatě se jedná o jinou variantu paragrafu, pouze nemá vlastnost diplay block
3. ### interaktivní elementy
- **Odkaz**
  - vytvářen párovou značkou **\<a>**
- **Tlačítko**
  - vytvářen párovou značkou **\<button>**
- **Obrázek**
  - vytvářen samoststnou značkou **\<img>**
- **Form label input**
  - **\<form>** - slouží ke tvorbě formuláře (párový)
  - **\<label>** - nadpis vstupu (párový)
  - **\<input>** - vstup (samostatný)
